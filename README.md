# Calculadora de Peças

Ferramenta para montar orçamentos de peças automotivas comparando fornecedores. Criada a partir de uma necessidade real do meu dia a dia no atendimento de uma oficina mecânica: cotar a mesma peça em vários lugares e descobrir qual compra sai mais em conta, já contando o frete.

## Funcionalidades

- **Orçamento:** cadastro das peças com tipo, quantidade, fornecedor e custo unitário
- **Cotações:** registro do preço da mesma peça em outros fornecedores
- **Comparação:** compara as cotações e ajuda a montar a melhor compra
- **Fornecedores:** frete, prazo de entrega e valor mínimo para frete grátis
- **Tipos de peça:** categorias personalizáveis (ex.: freio, suspensão, arrefecimento)
- **Margens:** cálculo da margem sobre o custo das peças
- **Backup:** exporta e importa todos os dados em um arquivo JSON

Os dados ficam salvos no próprio navegador (localStorage), sem necessidade de servidor.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

1. Clone o repositório ou baixe os arquivos
2. Abra o arquivo `index.html` no navegador
3. Cadastre seus fornecedores e tipos de peça
4. Monte o orçamento na aba **Orçamento**
